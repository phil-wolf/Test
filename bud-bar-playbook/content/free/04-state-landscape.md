# State landscape

## How to read the state table

The next screen lists recreational-legal states. Each one gets a status for running a bud bar:

- **Clear:** state rules give a clear path for at least one bud bar model.
- **Gray:** rules are unclear, untested, or changing. Get legal advice before booking.
- **Not permitted:** state rules currently do not allow the bud bar models in this course.

> This table is not legal advice. Statuses have not been filled in yet, and every one is marked [PHILIP TO VERIFY]. Rules change often, so always confirm with your state regulator and a cannabis attorney.

- **Clear:** confirm city and county rules and venue policies, then build your model.
- **Gray:** talk to a cannabis attorney before you take deposits.
